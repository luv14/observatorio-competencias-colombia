Calidad de datos y método de conteo

Las ofertas pueden aparecer en varios territorios: los totales territoriales no deben sumarse para obtener el total nacional. Las variantes de una misma oferta se conservan. Se usa la fecha de vencimiento informada, sin comprobar disponibilidad actual en el portal. La categoría nacional se mantiene separada. El histórico de cambios requiere nuevas descargas.
